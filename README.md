Password Generator

A simple and user-friendly Password Generator built using HTML, CSS, and JavaScript. The application allows users to generate secure passwords based on their preferred length and character types.

🚀 Features
🔐 Generate random passwords
🔢 Option to include numbers
🔣 Option to include special characters/symbols
📏 Customize password length
📋 Copy generated password to clipboard
🎨 Simple and responsive user interface
⚡ Built with pure JavaScript — no external frameworks
🛠️ Technologies Used
HTML5 — Structure
CSS3 — Styling and responsive design
JavaScript — Password generation and application logic

⚙️ How It Works
Enter your desired password length.
Select whether you want:
Numbers
Special characters
Click the Generate Password button.
The application creates a random password based on your selected options.
Use the Copy button to copy the password to your clipboard.

No installation is required.
